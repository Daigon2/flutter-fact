# Create ADR

Input: `$ARGUMENTS`

Produce:

- Title and status
- Context
- Decision drivers
- Considered options
- Decision
- Consequences
- Risks and mitigations
- Migration/rollback
- Validation
- Related decisions

Do not mark an ADR accepted without human approval.
