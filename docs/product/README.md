# Product Documentation

Canonical product truth for FACT.

Read selectively:

- `product-overview.md` — vision, users, principles and scope.
- `feature-roadmap.md` — feature inventory and release direction.
- `core-user-journeys.md` — observable user flows and edge cases.
- `../reference/glossary.md` — shared product and architecture terminology.
